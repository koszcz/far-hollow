# Every asset needs the owner's approval

No 3D model, texture, animation, or sound enters the game without the project owner's explicit approval. For each asset, the owner either approves a specific third-party file or asks for it to be built in code instead. Third-party assets come from free packs with no usage restrictions (CC0), such as Quaternius and Kenney. We chose this so the owner controls the game's look and every asset's license is known.
