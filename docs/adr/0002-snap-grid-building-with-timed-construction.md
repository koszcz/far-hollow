# Buildings use snap-grid pieces that take time to build

Players build structures from building pieces that snap to a grid, such as foundations, log walls, and roof sections. Each piece costs materials and takes time to build, with an animation that shows the player building it. Furniture is placed freely and does not snap. We chose a grid so players can design any cabin layout while walls, roofs, and floors still line up. Timed construction makes a large cabin feel earned.

## Considered options

- **Freeform placement**: rejected. Gaps and overlaps between walls and roofs are hard to prevent and hard to fix.
- **Blueprint mode (design first, build later)**: rejected as the main mode. Building each piece by hand fits the off-grid fantasy better.
