# 01: Build an igloo, and other things to do once the camp is set

**What to build:** Once the player has a warm cabin and steady food, they need fun things to do. Building an igloo from snow is the first example. This builds on the seasons and the snow cover.

**Status:** idea

**Assets:** None yet. Decide during grilling. Might reuse `snow-cover`.

Questions for grilling:

- When does the game count the player as "set"? Does it tell them?
- What does an igloo need: snow blocks cut by the player, a tool, a season?
- Is an igloo useful, such as a shelter or a respawn point, or only for fun?
- Which other activities belong in this group, and which comes first?
