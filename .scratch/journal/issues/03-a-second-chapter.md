# 03: A second journal chapter

**What to build:** After the first snug room, the journal suggests a second set of goals. Today the journal ends at the snug room, and the player has nothing more to aim for. The new goals lead the player through their first winter.

**Blocked by:** None, but most goals depend on `.scratch/seasons/` and `.scratch/food-keeping/`. Grill it after both.

**Status:** idea

**Assets:** None. The panel is text only and uses the existing panel style.

Questions for grilling:

- Which goals are in the second chapter? Candidates: build a fireplace, stack a woodpile of a set size, preserve food, store food for a set number of days, build a second storey, get through the first winter.
- Does the second chapter show only after the first is done, or do its goals appear in the same list?
- Does the closing line "Your camp is yours now." stay, move to the end of the second chapter, or change?
- How does the second chapter treat a player who already did some of its goals before it appeared?
- How do older saves fill in the second chapter's goals, as ticket 02 did for the first?
- Does the "Hide journal" toggle hide both chapters?
